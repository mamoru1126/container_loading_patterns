# 廃家電 コンテナ積付けデモ

リサイクル輸送する廃家電（家電4品目）を、コンテナに積み込むパターンを自動で作るデモです。2種類あります。
どちらもブラウザだけで動く1ファイルのHTMLにまとめています。

| デモ | ファイル | 公開ページ |
| --- | --- | --- |
| 計画型（積付けプランナー） | `dist/haikaden-planner.html`、Pages 用は `../index.html` | https://mamoru1126.github.io/container_loading_patterns/ |
| リアルタイム型 | `dist/haikaden-online.html`、Pages 用は `../online.html` | https://mamoru1126.github.io/container_loading_patterns/online.html |

## リアルタイム型でできること

- コンベヤでランダムに流れてくる家電を、1台ずつその場で判断して積む（先に何が来るかは使わない）
- 入らなくなったらコンテナを締めて、次の空コンテナに切り替える
- 積み方を選ぶ: 混載 / 家電4品目（冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、テレビ、エアコン）ごとに4本のコンテナへ仕分け
- 置き場所の判断を選ぶ: 遺伝的アルゴリズムで学習した判断 / 単純な奥詰め（比較用）
- 待機場所（コンベヤ脇に一時的に置ける台数）を 0・1・3台から選ぶ
- 流す台数（120・300・1,000台・止めるまで）と速さ（1倍〜最速）を選ぶ
- 締めたコンテナを選んで中身を3Dで見直す。各コンテナの制約チェック結果を表示する
- 同じ流れを積み方（混載・仕分け）・判断方法・待機場所を変えて一気に積み、本数と容積率を比べる

判断の仕組みと学習の方法は [リポジトリ直下の README](../README.md#積込みの計算方法リアルタイム型) にあります。

## 計画型でできること


- コンテナを選ぶ: JR 12ft（19D形）、ISO 20ft / 40ft / 40ft ハイキューブ
- 品目と台数を指定する: 冷蔵庫（3サイズ）、上開き冷凍庫、縦型・ドラム式洗濯機、衣類乾燥機、液晶テレビ（3サイズ）、ブラウン管テレビ（2サイズ）、エアコン室内機・室外機（各2サイズ）
- 3つの方針で積付けパターンを作り、比べる（案A〜C）
  - 品目ごとに整列: 同じ品目どうしだけを積み重ねる
  - 段積み優先: ルールの範囲で異なる品目も積み重ね、床面を節約する
  - 重量バランス: 重い列を中央に寄せ、重心のずれを最小にする
- 遺伝的アルゴリズム（案D）で積み方をさらに改善する。進化の様子をグラフで表示する
- 3Dで確認する: 家電らしい外観で表示し、積込みの順番をアニメーションで再生できる
- 制約チェック: 生成結果を独立した検査で確かめる（正立、積み重ねの組み合わせ、耐荷重、支持面積、干渉、天井とのすき間、最大積載重量、重心）

## 品目データ

寸法と質量は各メーカーの公表仕様（2026年10月に確認）を基準にしています。
廃家電はメーカーや年式が混ざるため、生成時に寸法へ ±4% 程度のばらつきを加えています。
出典は `src/catalog.js` とデモ画面下部の「寸法・仕様の出典」にあります。

## 積付けの考え方（`src/engine.js`、`src/ga.js`）

詳しい説明は [リポジトリ直下の README](../README.md#積込みの計算方法計画型) にあります。

1. **段組み**: 積み重ねルール（`src/catalog.js` の `CATS`）を守って、品目を「列（スタック）」にまとめる。液晶テレビはスタンドを付けたまま立てて前後に並べる。
2. **壁積み**: 奥の壁から扉に向かって、幅方向いっぱいの「壁」を順に作る（ブロック構築型ヒューリスティクス）。
3. **重心調整**: 壁の並び順と左右の寄せ方を入れ替えて、重心を中央に近づける。荷が余る場合は全体を中央に寄せ、前後の空きは固定材で埋める前提とする。
4. **多始点探索**: 方針ごとに乱数と評価の重みを変えて36回繰り返し、最もよい案を残す（案A〜C）。
5. **遺伝的アルゴリズム**: 品目の優先度・詰め方の重み・方針を遺伝子にして、40世代進化させる（案D）。

主な積み重ねルール

| 品目 | 上に載せてよいもの | 上の重さの上限 | 同じ品目の段数 |
| --- | --- | --- | --- |
| 冷蔵庫 | エアコン室内機 | 20 kg | 1 |
| 上開き冷凍庫 | 室内機・室外機・乾燥機 | 30 kg | 1 |
| 縦型洗濯機 | 縦型洗濯機・乾燥機・室外機・ブラウン管・室内機 | 50 kg | 2 |
| ドラム式洗濯機 | 洗濯機・乾燥機・室外機・ブラウン管・室内機 | 90 kg | 2 |
| 衣類乾燥機 | 乾燥機・室外機・室内機 | 30 kg | 2 |
| 液晶テレビ | なし | 0 kg | 1 |
| ブラウン管テレビ | 同じか小さいブラウン管・室内機 | 45 kg | 2 |
| エアコン室外機 | 室外機・室内機 | 60 kg | 3 |
| エアコン室内機 | 室内機 | 40 kg | 4 |

このほか、支持面積80%以上、片側のはみ出し60mm以内、重いものを軽いものの上に載せない、天井とのすき間50mm以上、を守ります。
数値はデモ用の仮置きで、現場の運用に合わせて調整する前提です。

## 開発

```sh
npm test         # 計画型（多始点探索・遺伝的アルゴリズム）とリアルタイム型の全コンテナに制約違反がないことを確認
npm run build    # dist/ の2つの HTML と ../index.html、../online.html を作る（esbuild が必要）
npm run train    # リアルタイム型の判断の重みを遺伝的アルゴリズムで学習し直す（約6分）
node test/screenshot.mjs   # ヘッドレス Chromium で画面を撮る（Playwright が必要）
```

3D表示は外部ライブラリを使わない小さな WebGL2 レンダラ（`src/gl.js`）で描いています。
家電のモデルは `src/models.js` にあります。
