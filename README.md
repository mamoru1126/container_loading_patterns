# container_loading_patterns

廃家電（家電4品目）をリサイクル輸送するときの、コンテナ積込みパターンを自動で作るソフトの開発リポジトリです。

## デモ

**https://mamoru1126.github.io/container_loading_patterns/**

コンテナと品目ごとの台数を選ぶと、積み重ねルール・耐荷重・重心を守った積付けパターンを3案作り、3Dで表示します。
積込みの順番をアニメーションで再生することもできます。詳しくは [`demo/README.md`](demo/README.md) を見てください。

### GitHub Pages の設定

- Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にする
- 公開されるのはリポジトリ直下の `index.html`（`demo/` のビルドで生成）
- `.nojekyll` を置いて、Jekyll による変換を止めている

デモを変更したら、ビルドして `index.html` も一緒にコミットします。

```sh
cd demo
npm test        # 積付けエンジンの制約チェック
npm run build   # index.html と demo/dist/haikaden-planner.html を生成
```

## 積込みの計算方法

### 問題の種類

オペレーションズ・リサーチでいう **3次元コンテナ積付け問題**（Container Loading Problem, CLP）です。
積む品目が事前に全部わかっている「オフライン型」で、品目の種類が少なく同じ形が多い「弱い異種混載」にあたります。
この種類の問題は厳密に解くと計算量が爆発するため、実務では **ヒューリスティクス（経験則にもとづく近似解法）** で解くのが一般的です。

### 使っている手法

**ブロック構築型ヒューリスティクス**（壁積み法）と、**ランダム多始点探索**（GRASP に近い方法）を組み合わせています。
AI・機械学習は使っていません。実装は `demo/src/engine.js` です。

| 段階 | 手法 | 内容 |
| --- | --- | --- |
| 1. 段組み | 貪欲法 | 重い品目から順に土台にし、積み重ねルールを満たす品目を上へ足して「列（スタック）」を作る。上に載せる候補は「高さを使い切れるか」「同じ品目か」などで点数を付けて選ぶ。エアコンは同じ型2台を並べて1段にでき、液晶テレビはスタンド付きで前後に並べた「束」にする |
| 2. 壁積み | 壁構築法（wall building） | 奥の壁から扉に向かって、幅方向いっぱいの「壁」を1枚ずつ作る。先頭の列の奥行で壁の厚みを決め、その厚みに収まる列を左から詰める。奥行が余れば同じ幅の中で後ろにも詰める |
| 3. 重心調整 | 局所探索（2要素の入れ替え） | 壁の並び順を入れ替えて、前後の重心をコンテナ中央に近づける。各壁を左寄せ・右寄せのどちらにするかを選んで左右の重心も整える。空きがあれば荷全体を中央に寄せ、前後の空きは固定材で埋める前提にする |
| 4. 多始点探索 | ランダム化＋重みのゆらぎ | 方針ごとに乱数と評価の重みを変えて36回解き直し、最も評価の高い案を残す（3方針で計108回） |
| 5. 検査 | 独立した検査 | 結果の配置だけを見て、干渉・支持面積・耐荷重・積み重ねの組み合わせなどを確認する（`demo/src/check.js`） |

### 3つの方針

| 方針 | 段組み | 壁の作り方 |
| --- | --- | --- |
| 品目ごとに整列 | 同じ品目どうしだけ積み重ねる（室内機は例外） | 同じ品目が同じ壁に集まるよう点数を加える |
| 段積み優先 | ルールの範囲で異なる品目も積み重ねる | 体積の大きい列から置く |
| 重量バランス | 段積み優先と同じ | 重い列から置き、重心調整を必ず行う |

### 評価の式

案どうしは次の点数で比べます（大きいほどよい）。最優先は積めた台数です。

```
点数 = 積載台数 × 1000 + 容積率(0〜1) × 100 − |前後重心のずれ(%)| × 1.5 − 使用長さ / 全長 × 5
```

壁に列を詰めるときは、次の重みで候補を選びます。1回目は固定値で、2回目以降は括弧内の範囲でランダムに変えます。

| 項目 | 意味 | 重み |
| --- | --- | --- |
| 奥行の一致 | 壁の厚みをどれだけ使い切るか | 0.6（0.4〜0.8） |
| 高さ | 列が天井近くまで届くか | 0.5（0.15〜0.65） |
| 幅 | 幅方向をどれだけ使うか | 0.2（0.1〜0.3） |
| 台数 | 列に何台入っているか | 0.04（0.02〜0.22） |

### 守っている制約

- 正立（冷蔵庫・室外機などを寝かせない。エアコン室内機は背面を下にして寝かせる）
- 品目ごとの「上に載せてよい品目」と「上に載せてよい重さ」（表は [`demo/README.md`](demo/README.md)）
- 支持面積80%以上、片側のはみ出し60mm以内、重いものを軽いものの上に載せない
- 天井とのすき間（初期値50mm）、列どうしのすき間（初期値20mm）
- 最大積載重量
- 前後の重心がコンテナ中央から±5%以内（CTUコードの目安）

### 計算時間

20ftコンテナに59台でおよそ0.2秒、40ftに160台でおよそ0.5秒（ブラウザ上）です。

```
  src/check.js        生成結果の制約チェック
  src/gl.js           WebGL2 レンダラ
  src/models.js       家電・コンテナの3Dモデル
  src/app.js          画面の動作
  src/page.html       画面のレイアウトとスタイル
  build.mjs           ビルドスクリプト
  test/               エンジンのテストとスクリーンショット
```
